## 三、录屏操作路径（按此顺序录，减少剪辑）

1. 启动后端：`DEMO_OFFLINE=1` 离线模式  
2. 打开前端 → 选择「张阿姨」  
3. 首页 → 等待主动预警横幅  
4. `/eeg` → 点击「开始评估」→ 展示 8 维 + 三大核心  
5. 切换「李大爷」→ 再次评估 → 风险升高 + 政策卡片  
6. `/policy` → 展示政策匹配省钱清单  
7. `/security/data-space` → 隐私计算开关  
8. `/chat` → 输入复合问题演示多智能体
