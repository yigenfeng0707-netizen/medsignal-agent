# 自动部署配置清单（5 分钟搞定）

> 目标：push 到 master → GitHub Actions 自动构建 → 前端部署 Vercel + 后端部署 Render
> 当前状态：✅ 代码已就绪，✅ deploy.yml 已修复，⏳ 需要你配置 3 个 secret + 1 个变量

---

## 总览：需要配置什么

| 配置项 | 在哪配 | 用途 | 必填？ |
|---|---|---|---|
| `DEPLOYMENT_ENABLED` (variable) | GitHub | 部署总开关（设为 `true` 才触发部署） | ✅ |
| `VERCEL_TOKEN` (secret) | GitHub | 前端部署到 Vercel 的凭证 | ✅（要部署前端） |
| `RENDER_DEPLOY_HOOK` (secret) | GitHub | 触发后端 Render 部署的 webhook | ✅（要部署后端） |
| Render 环境变量 | Render 控制台 | 后端的 LLM/OCR API Key | ✅（要 AI 功能） |

> 💡 全部不配也能用：CI 只跑 Build Test（验证代码可编译），不部署。现场可以本地 `pnpm dev` + `uvicorn` 跑。

## 步骤 1：配置 GitHub Secrets 和 Variable

打开：**https://github.com/yigenfeng0707-netizen/yibao-zhinao/settings/secrets/actions**

### 1.1 添加 Variable `DEPLOYMENT_ENABLED`（部署总开关）

> 注意：这是 **Variable**（变量），不是 Secret。在同一页面的 "Repository variables" 区。

1. 点击 **Add repository variable**
2. Name: `DEPLOYMENT_ENABLED`
3. Value: `true`
4. 点击 **Add variable**

### 1.2 添加 Secret `VERCEL_TOKEN`（前端部署）

1. 先去 Vercel 获取 token：
   - 打开 https://vercel.com/account/tokens
   - 点击 **Create Token**
   - Name: `github-actions-deploy`
   - Scope: `Full Account`（或选你的 team）
   - Expiration: `90 days`（或自定义）
   - 复制生成的 token（形如 `vercel_xxxxxxxxxxxx`）

2. 回到 GitHub Secrets 页面：
   - 点击 **New repository secret**
   - Name: `VERCEL_TOKEN`
   - Secret: 粘贴刚才的 token
   - 点击 **Add secret**

### 1.3 添加 Secret `RENDER_DEPLOY_HOOK`（后端部署）

1. 先在 Render 创建服务（见步骤 2），拿到 deploy hook URL
2. 回到 GitHub Secrets：
   - 点击 **New repository secret**
   - Name: `RENDER_DEPLOY_HOOK`
   - Secret: 粘贴 Render 的 deploy hook URL（形如 `https://api.render.com/deploy/srv-xxxxx?key=xxxxx`）
   - 点击 **Add secret**

## 步骤 2：配置 Render 后端服务

### 2.1 创建服务

1. 打开 https://dashboard.render.com
2. 点击 **New +** → **Blueprint**
3. 选择你的 GitHub 仓库 `yibao-zhinao`
4. Render 会自动读取 `render.yaml`，显示将创建的服务 `yibao-zhinao-api`
5. 在 "Environment Variables" 部分，**手动填入** sync: false 的变量：
   - `LLM_API_KEY`: 你的商汤 SenseNova Key（`sk-...`）
   - `DASHSCOPE_API_KEY`: 你的阿里 DashScope Key（`sk-...`）
   - `OCR_API_KEY`: 你的 OCR.space Key（`K...`）
   - `YIBAO_API_KEY`: （可选）自定义 API 鉴权 token
6. 点击 **Apply** 创建服务

### 2.2 获取 Deploy Hook URL

1. 服务创建后，进入服务详情页
2. 左侧菜单点击 **Settings**
3. 找到 **Deploy Hook** 区域，点击 **Add deploy hook**
4. Branch: `master`，随便取个名字如 `github-actions`
5. 复制生成的 URL（这就是步骤 1.3 要填的 `RENDER_DEPLOY_HOOK`）

### 2.3 验证后端

部署完成后（首次约 3-5 分钟），访问：
```
https://yibao-zhinao-api.onrender.com/api/health
```
应返回 `{"status":"ok","service":"MedSignal","version":"2.2.0"}`

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| Deploy Frontend job 不执行 | `DEPLOYMENT_ENABLED` 没设为 `true` | 检查 GitHub Variables |
| `--token=` missing value | `VERCEL_TOKEN` secret 没配 | 按 1.2 配置 |
| Render 部署"成功"但 API 访问不通 | hook URL 错或服务未启动 | 检查 Render 控制台服务状态 |
| 前端调用后端 404/CORS | Render 服务名或 URL 不匹配 | 确认 `vercel.json` 的 `NEXT_PUBLIC_API_URL` |
| Build Test 失败 | 代码编译错误 | 看 CI 日志，本地 `npm run build` 复现 |

## 路演备份方案（防现场网络问题）

即使云部署失败，Demo 也能跑：
1. **本地启动**：`cd backend && uvicorn app.main:app` + `cd frontend && pnpm dev`
2. **备份视频**：提前录制完整 Demo 流程视频存 U 盘
3. **降级模式**：后端 LLM 不可用时自动降级到规则引擎 + mock 数据

> 三级降级保证 Demo 绝不翻车（详见 README "容错降级"章节）。
