> **调研目的**：第一阶段目录级调研（仅收集元信息，不下载任何大文件），为项目影像引擎寻找合适的公开训练/评测数据集。

> **调研方式**：WebSearch + WebFetch 公开网页检索（官方站点、官方论文、第三方对比资料）。
> **说明**：文中"≈"表示近似统计，数据规模随平台版本更新会动态变化，落地接入前请以官方页面实时数据为准。

## 平台 1：The Cancer Imaging Archive (TCIA)

### 1.1 平台概述

- **官方 URL**：https://www.cancerimagingarchive.net/
- **国家/机构**：美国，国立癌症研究所（NCI）资助，由 University of Arkansas for Medical Sciences 等机构运行维护。
- **定位**：全球最大的**癌症影像**公开档案库，数据按"Collection（集合）"组织，覆盖 CT、MRI、PET、X-ray 等模态，多集合附带临床数据、病理与基因数据（TCGA 系列）。
- **规模**：2017 年即达约 3,090 万张影像、37,568 名受试者（Nature Scientific Data, 2017）；当前收录 100+ 个公开集合，每个集合分配独立 DOI。
- **数据分发**：公开 DICOM 数据现主要通过 **NCI IDC 云端分发**（TCIA 官方推荐路径），本地工具为 **TCIA Data Retriever / NBIA**；少量受限集合（如 NLST）需签署 DUA 后经专门通道获取。
- **对 MedSignal 的价值**：肺 CT（LIDC-IDRI/NLST）与脑 MRI（TCGA-GBM/LGG）的一手来源，是肺 CT 与脑 MRI 两条引擎线的核心候选。

| 元信息项 | 内容 |
|---|---|

## 平台 2：NCI Imaging Data Commons (IDC)

### 2.1 平台概述

- **官方 URL**：https://imaging.datacommons.cancer.gov/（门户：https://portal.imaging.datacommons.cancer.gov/）
- **国家/机构**：美国，NCI 资助（Brigham and Women's Hospital / Harvard 等团队建设），是 NCI Cancer Research Data Commons（CRDC）的影像节点。
- **定位**：**云原生**癌症影像数据 commons：把 TCIA 公开集合、TCGA、CPTAC、HTAN、CCDI 等来源的影像统一**DICOM 化**后托管在 **Google Cloud Storage + AWS 公共桶**。
- **规模**（Data Release 24.0，2026-04-27）：**176 个集合、85,682 例病例、1,032,911 个影像序列、99.27 TB**。
- **独特价值**：
  - **免注册、免登录**直接下载（S3 API / `idc-index` Python 包 / DICOMweb）；
  - **免费出口流量**（云厂商公共数据集计划支持，下载速度远快于 TCIA 本地服务器）；
  - 附带**衍生分析数据**：TotalSegmentator 全身解剖自动分割、影像组学特征等；
  - 数据**版本化**（v23/v24…），可复现；
  - 元数据全部可 **BigQuery SQL** 检索。
- **对 MedSignal 的价值**：上述 TCIA 全部公开集合（LIDC-IDRI、TCGA-GBM/LGG 等）都可以在 IDC 以更快速度、更工程化方式获取，且许可逐文件标注（`license_short_name` 字段），便于自动合规筛选。

### 2.2 平台级元信息（IDC）

| 元信息项 | 内容 |
|---|---|
| 国家和提供机构 | 美国；NCI（CRDC 影像节点），Harvard/BWH 团队建设 |
| 影像模态 | 26 种模态：CT、MR、PT、CR/DX（X-ray）、MG、US、Slide Microscopy（数字病理）等 |
| 身体部位和疾病 | 全身癌症（肾上腺、脑、乳腺、肺、前列腺…）+ 数字病理 |
| 访问方式 | **完全开放**：无注册、无凭据；IDC Portal / `idc-index` / S3 API / DICOMweb / BigQuery（BigQuery 需 GCP 账号） |
| 许可证/DUA | **按 DICOM 对象逐文件标注**：97%+ 序列为 CC BY 4.0 / CC BY 3.0；约 3% 为 CC BY-NC 4.0 / 3.0；极少数自定义条款 |

| 已知限制 | 不托管 TCIA 受限集合（NLST 完整版不在其中）；衍生分割多为 AI 自动生成（非人工金标准） |

## 平台 3：MIDRC（Medical Imaging and Data Resource Center）

### 3.1 平台概述

## MedSignal 项目适配推荐

> MedSignal 三条影像引擎线：**① 胸片（CXR）病灶检测；② 肺 CT 病灶检测；③ 脑 MRI 病灶检测**。
> 评估维度：模态/病种匹配度、标注质量与类型（检测需 bbox/分割）、规模、许可（能否商用/发权重）、接入成本。

### 6.1 推荐矩阵总览

| 引擎线 | 首选数据集 | 备选/增强数据集 | 规避/谨慎 |
|---|---|---|---|
| **胸片（CXR）** | **NIH ChestX-ray14**（11 万张、14 类、可商用口径宽松） | **CheXpert/CheXpert Plus**（22 万张、标签质量高、含报告文本，**但非商业 RUA**）；MIDRC-RICORD 1a（专家标注小集，做评测集） | ChestX-ray14 直接用官方划分有患者泄漏风险（需按 patient 重划）；CheXpert 不可商用 |
| **肺 CT** | **LIDC-IDRI（IDC 云端版）**（1,018 例、4 医生结节标注、CC BY 3.0 可商用） | LUNA16（LIDC 子集派生，检测任务即用型）；NLST（大规模预训练/弱监督，**需 DUA 且非商业**）；MIDRC 胸部 CT（真实世界 + 临床数据，**商用需另签 DUA**） | NLST/DUA 数据不可用于商用产品 |
| **脑 MRI** | **TCGA-LGG + TCGA-GBM + UPenn 分割标签**（461 例原始 / 243 例专家分割、CC BY 3.0 可商用） | BraTS 挑战赛历年数据（同源+更多中心病例，注册获取）；MIDRC 头部数据（少量） | 脑 MRI 公开库以胶质瘤单病种为主，"多病种病灶检测"需后续扩展（脑转移/脑卒中另寻库） |

### 6.2 分线落地建议

**① 胸片引擎 —— ChestX-ray14 为主 + CheXpert 为辅 + RICORD 做金标准评测**

1. **主训练库选 ChestX-ray14**：
   - 理由：11 万张规模最大、14 病种标签覆盖 MedSignal 目标病灶（结节/肿块/肺炎/气胸/积液/实变等）、官方无禁止商用条款、可发布权重、接入零门槛（Box/GCS 直接下载，约 42 GB）。
   - 落地要点：**必须按 patient ID 重划分 train/test**（官方划分有患者重叠）；bbox 仅 880 个（约 1% 图像），检测任务采用"分类预训练 + bbox 微调"或弱监督定位（Grad-CAM/CAM）；标签噪声建议用 CheXpert labeler 复核或清洗。
2. **增强库选 CheXpert**（若项目保持学术/科研定位）：
   - 22 万张、三值不确定标签、500 例放射科医生金标准测试集——**评测质量高于 ChestX-ray14**；
   - CheXpert Plus 提供配对报告，可支撑"检测 + 报告生成"叙事（与 MedSignal 的 AI 解释/报告功能契合）；
   - **注意 RUA 非商业限制**：若 MedSignal 计划商业化，CheXpert 权重只能用于研究验证，商用版本须仅基于 ChestX-ray14 等可用数据重训。
3. **评测集选 MIDRC-RICORD 1a**：专家级标注（但需 MIDRC 注册 DUA；商用另行评估）。

**② 肺 CT 引擎 —— LIDC-IDRI 为主（IDC 云端通道）+ LUNA16 派生 + NLST 视情况**

1. **主训练库选 LIDC-IDRI**：
   - 理由：肺结节检测的事实标准基准；4 名放射科医生逐层标注（可转 bbox + 分割掩码两种监督信号）；CC BY 3.0 **允许商用与权重发布**；1,018 例规模适中（CT 引擎冷启动足够）。
   - 落地要点：经 **IDC 云端**下载（免注册、速度快、`idc-index` 程序化获取）；标注 XML 需解析为 3D bbox/掩码；社区有 **LUNA16**（888 例子集 + 结节质心/直径 CSV + 肺分割掩码，CC BY 4.0）可作为"即用型"补充，减少预处理成本。
2. **规模化阶段引入 NLST**（26,254 例低剂量 CT）：
   - 用途：自监督预训练（如 MAE/对比学习）+ 患者级弱标签监督；
   - **注意**：TCIA 版需 DUA 且非商业；IDC 版按文件级 license 字段核验可用范围。
3. **真实世界分布对齐**：MIDRC 胸部 CT（多中心 27 家医院、含临床数据与报告）适合做域适应/外部验证，但商用需与芝加哥大学单独签约。

**③ 脑 MRI 引擎 —— TCGA-LGG/GBM + UPenn 分割标签为主**

1. **主训练库选 TCGA-LGG + TCGA-GBM（配 UPenn/Bakas 专家分割）**：
   - 理由：唯一规模化（数百例）、带**专家像素级分割**（水肿/瘤芯/增强核心三亚区，直接支撑"病灶检测+分割"）、**附带生存期与分子病理（IDH/1p19q）**数据、CC BY 3.0 可商用；
   - 落地要点：直接取 UPenn 发布的 NIfTI 版（已配准、去颅骨、1 mm³），免去 DICOM 预处理大头；243 例偏少，建议**迁移学习**（如 nnU-Net 在 BraTS 预训练 → TCGA 微调）或融合 BraTS 历年数据（注册获取）扩充。
2. **路线图提醒**：当前 5 个平台中脑 MRI 资源集中在胶质瘤单病种；MedSignal 若扩展脑转移瘤/脑卒中等病种，需第二阶段调研（如 BraTS-MET、RSNA-ASNR 卒中挑战库等，不在本次范围）。

### 6.3 合规与工程化注意事项（跨平台通用）

1. **许可优先级**：商用路线可用 = LIDC-IDRI / TCGA-LGG&GBM / ChestX-ray14 / IDC(CC BY 部分)；**不可商用 = CheXpert(RUA)、NLST(DUA)、MIDRC(除非另签)**。若 MedSignal 面向比赛/科研展示，则全部可用。
2. **引用义务**：无论商用与否，每个数据集都要求引用指定论文与 DOI（各表第 15 项已列全），产品白皮书/答辩材料中应完整列出。
3. **下载通道**：优先 **IDC 云端**（免注册、S3 直连、免费出口流量、`idc-index` 程序化）；TCIA 原站速度慢；ChestX-ray14 走 Box/GCS；MIDRC/CheXpert 需走注册流程（建议尽早提交 DUA/RUA 申请，留出审批时间）。
4. **已知坑**：
   - ChestX-ray14 患者重叠泄漏 + NLP 标签噪声；
   - LIDC-IDRI 多读片者标注不一致（无唯一金标准，需定义共识规则）；
   - CheXpert 不确定标签策略需固定（建议 U-Ignore/U-MultiClass 并报告消融）；
   - MIDRC 部分标注为 Helper AI 自动生成（非人工金标准，需按 annotation name 过滤）。
5. **第二阶段建议**：确定入选数据集后，先下载各库的**小型样本**（IDC 支持 series 级选取；LUNA16 有子集 zip）做管线打通（DICOM→预处理→训练→推理→报告），再决定全量拉取与存储规划（预估首期全量约 200 GB 量级：ChestX-ray14 ≈42 GB + LIDC ≈130 GB + TCGA 脑瘤 ≈20–40 GB）。
