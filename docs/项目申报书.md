# 项目申报书

## VentureD Hackathon · 医疗赛道（Diagens 德适科技）

---

### 一、项目基本信息

**项目名称**：MedSignal —— 多模态医疗信号识别智能体

**参赛赛道**：医疗赛道 · AI 智能体（方向：关键医疗信号识别 / 患者信息理解与连接）

**项目定位**：围绕真实医疗场景中"关键医疗信号"的识别与翻译，构建"脑电信号（EEG）→ 医学影像信号 → 生理行为信号 → 患者信息连接"的多智能体系统，让 AI 帮助医生与患者不遗漏任何关键医疗信号，实现从"被动就医"到"主动健康管理"的范式转变。

**一句话亮点**：AI 预标注病灶、医师复核裁决的影像工作流 + 可解释的脑电频域健康指标 + 政策红利的自动连接。

---

### 二、项目背景与痛点

#### 2.1 真实医疗场景

**场景 1 · 脑电信号被忽视**：压力、睡眠、认知状态是最普遍的健康信号，但普通人没有可及的客观指标。我国焦虑抑郁人群超 9000 万，认知障碍患者超 5000 万，脑血管疾病年发病人数超 300 万。脑电监测长期停留在医院重症场景，消费级 EEG 设备的普及让早期筛查成为可能，却没有应用把它变成健康行动。

**场景 2 · 影像阅片供需失衡**：基层影像医师短缺，日均阅片量超负荷，工作数小时后漏诊风险显著上升。AI 辅助阅片已是大势所趋，但"AI 直接出报告"在医疗安全上不可接受——缺少"AI 预标注 + 医师复核"的人机协同闭环。

**场景 3 · 政策信息鸿沟**：80% 参保人不知道自己能享受哪些医疗待遇，报销计算复杂难懂，每年错过的政策红利以千元计。

#### 2.2 核心问题

关键医疗信号（脑电的、影像的、信息的）存在于每个人身边，但：**信号有，识别没有；识别有，翻译没有；翻译有，行动没有。**

### 三、技术方案

#### 3.1 系统架构（1+7 多智能体）

- **1 个编排智能体**：意图识别 + 信号路由 + 多智能体并行调度 + 结果聚合
- **信号识别层（赛道方向：关键医疗信号识别）**
  - **脑电卫士** ⭐：EEG 频域分析 → 五维健康指标 → 主动预警
  - **影像卫士** ⭐：医学影像病灶检测 → AI 预标注 → 医师逐框复核 → 结构化报告
  - **健康卫士**：用药/就医/购药行为信号 → 慢病风险评分 → 主动预警
- **信息连接层（赛道方向：患者信息理解与连接）**
  - **权益管家 / 报销助手 / 政策参谋**：把专业医疗与政策信息翻译成患者可理解、可行动的建议
- **安全合规层**
  - **安全守门**：数据授权管理 + 可信数据空间 + 区块链存证 + 产品使用边界

#### 3.2 脑电信号引擎（核心创新）

**信号采集**：支持消费级 EEG 设备（Muse 4 通道 TP9/AF7/AF8/TP10，256Hz，LSL 协议）+ 合成信号模拟 + 文件导入

**频域分析**：FFT + Welch PSD（Hann 窗 + 50% 重叠）→ δ/θ/α/β/γ 五频段功率积分

**健康指标**（五维 + 异常预警，0-100 归一化）：

| 指标 | 算法依据 | 临床意义 |
|---|---|---|
| 压力指数 | α/β 比值反演 | 长期压力影响心血管 |
| 注意力指数 | θ/β 比值反演 | 注意力下降影响生活 |
| 睡眠质量 | δ+θ 占比 | 深睡相关频段 |
| 认知负荷 | β+γ 占比 | 脑力消耗程度 |
| 情绪状态 | α 不对称性 + β 活跃度 | 焦虑/低落倾向 |

**异常预警**（带 evidence 可解释）：高压力 / 睡眠差 / 认知过载 / 注意力低 / 情绪异常，脑电异常自动联动相关医疗待遇

**数据来源**：真实脑电算法基于公开 EEG 文献中的频域指标方法；演示数据为基于临床分布的仿真信号，不涉及真实患者隐私

#### 3.3 医学影像引擎（核心创新）

**病灶生成**：按真实解剖位置分布确定性生成病灶（位置/大小/严重度参数化）

**影像渲染**：SVG 内联渲染高仿真医学影像（胸片/肺 CT/脑 MRI 三类检查）

**AI 预标注**：bbox 归一化坐标 + 置信度 + 严重度分级（高/中/低危）

**医师复核工作流（Human-in-the-Loop）**：
- AI 预标注 → 医师逐框确认/驳回 → 点击影像新增医生标注
- 复核通过 → 生成最终结构化报告（病灶清单 + 风险等级 + 就诊建议）
- 影像异常自动联动相关政策与就诊建议

**安全边界**：AI 预标注是建议，医师复核是裁决；报告必须医师复核后生成

#### 3.4 行为信号引擎

用药/就医/购药模式分析 → 五维健康画像（慢病管理/依从性/风险暴露等）→ 分级预警（🔴/🟡/🟢）→ 主动推送复查与政策建议

#### 3.5 患者信息连接层

- **报销助手**：OCR 票据识别 + 7 步报销推导逐行展示 + 大病保险
- **政策参谋**：用户画像精准匹配 + 省钱金额排序 + 政策原文引用
- **权益管家**：一句话查权益，主动提醒缴费年限

#### 3.6 医疗安全与数据合规

- **医疗安全**：影像报告必须医师复核签字；脑电/健康预警明示"提示非诊断"；不做处方、不做确诊；危急信号引导线下就医
- **隐私保护**：用户自主授权 + 隐私计算"可用不可见" + 区块链存证可追溯
- **合规对齐**：对齐"数据要素×医疗健康"国家战略与《个人信息保护法》《数据安全法》

---

### 四、创新亮点

1. **多模态信号识别**：脑电 + 影像 + 行为三类关键医疗信号，由编排智能体统一调度，复合意图并行执行
2. **医师在环（Human-in-the-Loop）**：影像 AI 预标注必须医师逐框复核才能出报告——建议权给 AI，裁决权给人
3. **可解释脑电指标**：五维健康指标均有频域证据链，非黑箱输出
4. **全链路可解释**：脑电有频域依据、病灶有坐标框、政策有原文引用、报销有步骤推导
5. **可信数据空间对齐**：隐私计算 + 区块链存证 + 授权管理，医疗数据"可用不可见"
6. **容错降级**：LLM/知识库/前端三级降级，保证演示不翻车

---

### 五、应用场景

1. **基层影像复核**：基层医生使用影像工作台，AI 预标注缓解阅片压力，医师复核守住质量底线
2. **职场脑健康监测**：高压行业员工脑电监测 → 疲劳/压力预警 → 心理健康服务引导
3. **慢病主动管理**：用药行为分析 → 慢病风险预警 → 复查提醒 + 门诊慢病待遇联动
4. **患者信息普惠**：报销预审 + 政策匹配，让患者拿到应得的政策红利

### 六、产业化路径

- **Phase 1（1-3 个月）**：与基层医疗机构/体检机构联合试点影像复核工作流，接入真实脱敏数据验证
- **Phase 2（3-6 个月）**：扩展 2-3 家医疗机构，覆盖更多影像类型与 EEG 设备，迭代产品
- **Phase 3（6-12 个月）**：医疗器械软件（SaMD）注册路径规划，依托可信数据空间规模化部署

**商业模式**：
- **To G**：为医院/卫健/医保机构提供影像 AI 辅助复核、智能客服，降低服务成本
- **To B**：为体检机构/商保/药企提供脱敏信号分析能力（API 调用/数据服务）
- **To C**：基础信号识别免费，健康管理增值服务付费（会员/单次）

### 九、社会价值

1. **范式转变**：健康管理从"等生病"到"早发现"
2. **早筛早防**：脑电/影像/行为信号提前捕捉异常，降低疾病发现成本
3. **基层赋能**：影像 AI 预标注缓解基层阅片压力，医师复核守住质量
4. **信息普惠**：让患者看得懂信号、拿得到政策红利
5. **数据价值释放**：在隐私计算保护下释放医疗数据要素价值，对齐"健康中国"战略
