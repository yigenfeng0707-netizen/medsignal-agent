# 项目申报书

## 全球脑机接口×医保创新场景大赛 · 场景应用赛道

---

### 一、项目基本信息

**项目名称**：医保智脑——基于BCI脑电监测的医保主动健康服务智能体

**参赛赛道**：场景应用赛道（赛道7：芯测预警——脑血管疾病预警、认知与精神状态早期筛查、行业人群脑健康监测）

**项目定位**：将脑机接口（BCI）脑电监测技术与医保数据要素深度融合，构建"脑电采集→健康评估→风险预警→医保政策联动"的全链路智能服务，实现从"被动报销"到"主动健康"的范式转变。

---

### 二、项目背景与痛点

#### 2.1 社会背景

我国脑血管疾病年发病人数超300万，认知障碍患者超5000万，焦虑抑郁人群超9000万。早期发现、早期干预可显著降低疾病负担。然而：

1. **筛查覆盖率低**：常规体检缺乏脑功能筛查，脑血管病首发即重症比例高
2. **认知衰退隐匿**：轻度认知障碍（MCI）早期无明显症状，确诊时已进展
3. **精神健康忽视**：焦虑抑郁早期识别率不足30%，错过最佳干预窗口
4. **医保政策信息不对称**：80%参保人不知道可享受的脑健康相关医保待遇

#### 2.2 技术机遇

脑机接口技术使脑电监测从实验室走向消费级场景。结合医保数据要素战略，可实现：
- 脑电异常 → 自动识别脑血管/认知/精神风险
- 风险预警 → 自动联动医保政策（门诊慢病/检查报销/绿色通道）
- 主动健康 → 从"生病报销"到"预警预防"

### 三、技术方案

#### 3.1 系统架构

采用"1+6+N"多智能体架构：
- **1个编排智能体**：意图识别 + 路由分发 + 结果聚合
- **6个专业智能体**：权益管家、报销助手、健康卫士、政策参谋、安全守门、**脑电卫士**（BCI创新）
- **N个应用场景**：权益查询、报销预审、健康画像、政策匹配、脑电健康评估

#### 3.2 BCI脑电健康引擎（核心创新）

**信号采集**：支持消费级EEG设备（Muse 4通道 TP9/AF7/AF8/TP10，256Hz）+ 合成信号模拟 + 文件导入

**频域分析**：Welch PSD（Hann窗+50%重叠+FFT）→ δ/θ/α/β/γ 五频段功率积分

**健康指标计算**（8维，0-100归一化）：

| 指标 | 算法依据 | 临床意义 |
|---|---|---|
| 压力指数 | α/β比值反演 | 长期压力影响心血管 |
| 注意力指数 | θ/β比值反演 | 注意力下降影响生活 |
| 睡眠质量 | δ+θ占比 | 深睡相关频段 |
| 认知负荷 | β+γ占比 | 脑力消耗程度 |
| 情绪状态 | α不对称性+β活跃度 | 焦虑/低落倾向 |
| **脑血管风险** ⭐ | δ波激增+θ/α升高+α波抑制 | 脑血管功能异常早期预警 |
| **认知衰退风险** ⭐ | θ/α比值升高+α波相对功率降低 | 轻度认知障碍(MCI)筛查 |
| **精神状态筛查** ⭐ | 焦虑评分+抑郁评分综合 | 焦虑/抑郁倾向量化 |

**异常预警**（8条规则，带evidence可解释）：
- 常规5条：高压力/睡眠差/认知过载/注意力低/情绪异常
- **赛道7核心3条**：脑血管风险≥60/认知衰退≥60/精神状态焦虑抑郁≥60

**医保政策联动**（8条规则）：
- 脑血管病门诊慢病待遇 / 脑卒中绿色通道 / 颈动脉超声医保报销
- 老年认知功能筛查 / 阿尔茨海默病门诊慢病 / 认知康复训练报销
- 心理治疗医保报销 / 抑郁症焦虑症门诊慢病 / PHQ-9/GAD-7量表筛查

#### 3.3 医保数据要素对齐

对齐浙江省医保数据要素战略"1+3+N"框架：
- **1个数据底座**：统一数据治理
- **3个核心能力**：隐私计算（可用不可见）、区块链存证（可信可追溯）、数据沙箱（可控可计量）
- **N个应用场景**：脑电健康评估即为典型场景

#### 3.4 全链路可解释性

每个决策都有来源：脑电指标有频段依据，预警有阈值规则，政策推荐有原文引用。不做黑箱AI，做参保人能信任的AI。

### 四、创新亮点

1. **BCI×医保全链路创新**：国内首个将脑电监测与医保政策联动，实现"脑电异常→风险预警→医保政策自动推荐"
2. **赛道7三大能力全覆盖**：脑血管预警+认知衰退筛查+精神状态筛查，均有临床脑电标志物依据
3. **多智能体协作**：6个专业智能体+编排器，支持脑电+政策复合意图并行调度
4. **消费级BCI适配**：支持Muse等消费级设备，降低脑电监测门槛
5. **主动健康范式**：从"生病找医保"到"脑电预警+医保主动服务"

---

### 五、应用场景

1. **社区脑健康筛查**：社区卫生服务中心配备EEG设备，老年人定期脑电筛查→脑血管/认知风险预警→医保政策指导
2. **职场脑健康监测**：高危行业（交通/医疗/能源）员工定期脑电监测→疲劳/压力预警→心理健康医保服务
3. **慢病管理增强**：糖尿病/高血压患者脑电监测→脑血管并发症早期预警→门诊慢病待遇联动
4. **精神健康早期识别**：脑电精神状态筛查→焦虑抑郁倾向量化→心理治疗医保报销引导

### 六、产业化路径

- **Phase 1（1-3个月）**：接入浙江省医保数据赋能实验室沙箱，脱敏数据验证
- **Phase 2（3-6个月）**：选择1-2个区县试点，覆盖5-10万参保人
- **Phase 3（6-12个月）**：全省推广，依托医保数据要素基础设施

**商业模式**：
- To G：为医保部门提供智能客服+脑健康筛查服务，降低经办成本
- To B：为商保/药企提供脑健康数据赋能，支撑精准定价
- To C：基础脑电评估免费，深度健康管理增值服务付费
