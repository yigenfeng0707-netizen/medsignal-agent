## 二、三大算法引擎（P1）

### 1. 报销计算引擎 `claims_engine.py`
- **能力**：7 步分步推导（费用分类→乙类自付→统筹→起付线→比例→封顶→大病）
- **大病保险**：分段累进（0-5万60% / 5-10万70% / 10万+80%）
- **调整因子**：慢病+10% / 异地-5% / 退休+5%，比例上限 96%
- **多场景对比**：社区/二级/三级 × 慢病 × 异地
- **规则库**：`data/reimbursement_rules.json`（南京职工/居民医保真实参数）
- **测试**：14 项单元测试全过

### 2. 健康风险评分引擎 `health_engine.py`
- **核心创新**：从"被动报销"到"主动预防"
- **5 维评分**：慢病管理 / 用药规范 / 就医频率 / 健康指标 / 生活方式
- **用药相互作用**：基于 `drug_interaction_rules.json` 检测（阿司匹林+抗凝药等）
- **主动预警**：购药间隔缩短 / 用药中断 / 就医异常 / 高龄关注
- **可解释性**：每条预警带 evidence 数据证据
- **测试**：11 项单元测试全过

### 3. 政策精准匹配引擎 `policy_matcher.py`
- **能力**：用户画像 → 政策特征 → 规则匹配 + 省钱计算
- **匹配维度**：慢病（糖尿病/高血压/冠心病）/ 年龄（65+体检）/ 参保类型 / 支出（大病保险）/ 退休待遇
- **省钱计算**：基于用户历史支出 × 报销比例提升
- **知识库补充**：从 `policy_knowledge.json`（18 篇）关键词匹配补充
- **测试**：12 项单元测试全过

## 九、v2.1.0 EEG 脑电健康模块（BCI×医保创新）

### 1. 脑电健康引擎 `eeg/engine.py` ⭐⭐
- **核心创新**：将 EEG 脑电指标纳入医保健康画像，实现"脑电采集 → 健康评估 → 医保联动"全链路
- **合成信号生成**：4 通道（TP9/AF7/AF8/TP10，Muse 布局）/ 256Hz 采样率 / 5 种心理状态预设
- **频域分析**：Welch PSD（Hann 窗 + 50% 重叠 + FFT）→ δ/θ/α/β/γ 五频段功率积分
- **健康指标**：压力指数（α/β 比值）/ 注意力（θ/β 比值）/ 睡眠质量（δ+θ 占比）/ 认知负荷（β+γ 占比）/ 情绪（valence/arousal）
- **异常预警**：5 条规则扫描（高压力/睡眠差/认知过载/注意力低/情绪异常），每条带 evidence
- **医保政策联动**：`eeg_policy_link.json` 规则库，脑电异常自动推荐相关医保政策
- **测试**：55 项单元测试全过（10 个测试类覆盖全部功能）

### 2. 脑电卫士智能体（第 6 个 Agent）
- **编排器集成**：`AGENT_KEYWORDS` 新增 eeg 意图（脑电/EEG/压力/睡眠/注意力/认知负荷/情绪/心理/BCI）
- **路由分发**：`route_to_agent()` 新增 eeg 分支，EEG 评估 + LLM 解读 + 结构化降级
- **复合意图**：eeg+policy 联动（"脑电压力+政策省钱"→ 并行调度）
- **Agent 提示词**：`EEG_AGENT_PROMPT` 定义脑电卫士角色、频段知识、联动规则、输出格式
- **智能体标签**：前端聊天界面"脑电卫士"紫色标签 + 多智能体协作徽章

### 3. EEG 路由 `routers/eeg.py`（6 个 API）
- `GET /api/eeg/states` — 心理状态列表（5 种状态）
- `POST /api/eeg/{user_id}/session` — 发起 EEG 采集会话（合成信号 + 完整评估 + 入库）
- `GET /api/eeg/{user_id}/latest` — 最近一次评估
- `GET /api/eeg/{user_id}/history` — 历史趋势
- `GET /api/eeg/{user_id}/realtime` — 实时数据块（前端轮询模拟实时采集）
- `GET /api/eeg/{user_id}/policy-links` — 脑电异常→医保政策联动

### 4. 数据模型与初始化
- `EEGRecord` 模型：session_id/mental_state/avg_band_powers(JSON)/metrics(JSON)/alert_count/policy_link_count/summary
- CRUD 层：`create_eeg_record()` / `get_eeg_records()` / `get_latest_eeg_record()` / `eeg_record_to_dict()`
- `init_db.py` 新增 EEG 记录初始化：为每个用户生成 3 条历史记录（共 30 条）

### 5. 前端脑电健康页面 `/eeg`
- 4 通道实时波形图（ECharts 折线 + Framer Motion 动画）
- 五频段功率柱状图（δ/θ/α/β/γ）
- 四维健康指标环形图（压力/注意力/睡眠/认知负荷）
- 脑电异常预警卡片（带 evidence 展开）
- 医保政策联动推荐卡片（BCI×医保创新可视化）
- 历史趋势折线图 + 实时流模拟
- 心理状态切换（5 种状态一键对比）

### 6. 主动预警增强
- `proactive-alerts` 端点合并 EEG 脑电预警（v2.1.0 升级）
- 首页横幅展示脑电预警（紫色"脑电"标签 + 跳转脑电页面入口）
- 脑电异常主动推送：高压力/睡眠差/认知过载等异常自动出现在登录预警中

### 7. 侧边栏与首页集成
- 侧边栏新增"脑电健康"导航项（Brain 图标）
