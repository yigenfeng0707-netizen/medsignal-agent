# MedSignal 用户测试报告

> **项目**：多模态医疗信号智能体（MedSignal）
> **测试周期**：2026-08-20 – 2026-08-27
> **测试环境**：线上部署（魔搭创空间 Docker 镜像）+ 本地测试套件
> **用途**：支撑「场景实用性」「群众可及性」评分维度，作为申报书附录与答辩支撑材料

---

## 一、测试概述

本次测试分两个层级：

1. **系统级测试**（已完成）：自动化单元测试、真实公开数据集接入验证、线上端点验证——数据全部来自实际运行结果
2. **用户可用性测试**（SUS 量表）：面向 5–10 名被试的居家/模拟居家测试——本节提供记录框架，随实际测试补充

---

### 2.2 脑电算法验证（合成信号交叉验证）

| 指标 | 结果 |
|---|---|
| 三分类准确率（放松/专注/压力） | **92.22%** |

| 三分类平均 AUC | **0.987** |
| 样本量 / 特征数 | 360 样本 / 21 维特征 |

### 2.3 真实公开数据集接入验证

**脑电（PhysioNet eegmmidb，ODC-By 许可）：**

| 验证项 | 结果 |
|---|---|
| EDF 文件解析 | S001R01 / S001R02（64 通道、160Hz、BCI2000 列式信号头） |
| 解析方式 | 纯 Python EDF 解析器（无 pyedflib 依赖，支持行式/列式两种布局） |
| 五维健康指标输出 | 压力/注意力/睡眠/认知负荷/情绪 |
| 预警与政策联动 | 异常脑电模式 → 医保政策推荐 |
| API 端点 | `GET /api/eeg/real/list` · `GET /api/eeg/real/{record_id}` |

**影像（公开胸片数据集，脱敏科研用途）：**

| 验证项 | 结果 |
|---|---|
| 影像标准化 | 灰度归一化 → 标准 PNG 输出 |
| AI 病灶检测 | 预标注框 + 置信度 + 严重度分级 |
| GT 对比评估 | IoU / 检出率 / 精度指标（有 GT 数据源时） |
| API 端点 | `GET /api/imaging/real/list` · `GET /api/imaging/real/{study_id}` |
