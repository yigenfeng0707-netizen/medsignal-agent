## 方式一：本地开发部署（推荐体验）

最快 5 分钟启动，适合开发调试和功能体验。

### 1.1 克隆仓库

```bash
git clone https://github.com/yigenfeng0707-netizen/medsignal-agent.git
cd medsignal-agent
```

### 1.2 后端启动

```bash
cd backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# macOS / Linux:
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量
copy .env.example .env          # Windows
# cp .env.example .env           # macOS / Linux
# 编辑 .env，填入你的 API Key（可选，不填则降级模式）

# 初始化数据库 + 生成演示数据
python scripts/init_db.py

# 启动后端服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

后端启动后访问：
- API 服务：http://localhost:8000
- API 文档（Swagger）：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/health

### 1.3 前端启动

新开一个终端窗口：

```bash
cd frontend

# 安装依赖
npm install
# 或使用 pnpm（更快）：
# pnpm install

# 配置后端地址（默认 localhost:8000，通常无需修改）
# 如后端不在本地，创建 .env.local：
# echo "NEXT_PUBLIC_API_URL=http://你的后端地址:8000" > .env.local

# 启动开发服务器
npm run dev
```

前端启动后访问：http://localhost:3000

### 1.4 验证启动成功

1. 打开浏览器访问 http://localhost:3000
2. 页面应显示 MedSignal 首页，左上角有用户切换器
3. 点击右上角 API 状态指示灯，应显示"已连接"
4. 在对话框输入"我的医保卡里有多少钱"，应收到 AI 回复

## 方式二：Docker 一键部署

适合快速部署完整环境（含 PostgreSQL + Redis + ChromaDB）。

### 2.1 前置条件

- Docker Desktop 已安装并运行
- Docker Compose 可用

### 2.2 配置环境变量

在项目根目录创建 `.env` 文件：

```bash
# 必填：LLM API Key
LLM_API_KEY=your-sensenova-api-key
LLM_BASE_URL=https://token.sensenova.cn/v1
LLM_MODEL=sensenova-6.7-flash-lite

# 可选：备选 LLM
DASHSCOPE_API_KEY=your-dashscope-api-key
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_MODEL=qwen-plus

# 可选：OCR
OCR_API_KEY=your-ocr-space-api-key
OCR_API_URL=https://api.ocr.space/parse/image
```

### 2.3 一键启动

```bash
# 在项目根目录执行
docker-compose up -d --build
```

这将启动 5 个服务：

| 服务 | 端口 | 说明 |
|---|---|---|
| frontend | 3000 | Next.js 前端 |
| backend | 8000 | FastAPI 后端 |
| postgres | 5432 | PostgreSQL 数据库 |
| redis | 6379 | Redis 缓存 |
| chromadb | 8001 | 向量数据库 |

### 2.4 初始化数据

```bash
# 进入后端容器初始化数据库
docker-compose exec backend python scripts/init_db.py

# 构建知识库（可选，提升政策检索质量）
docker-compose exec backend python scripts/build_knowledge_base.py
```

### 2.5 访问应用

- 前端：http://localhost:3000
- 后端 API：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/health/detailed

### 2.6 停止与清理

```bash
# 停止所有服务
docker-compose down

# 停止并删除数据卷（清空所有数据）
docker-compose down -v
```

## 方式三：云端生产部署

### 3.1 前端部署到 Vercel（免费）

```bash
# 安装 Vercel CLI
npm i -g vercel

# 在 frontend 目录执行
cd frontend
vercel

# 按提示操作：
# ? Set up and deploy "~/medsignal-agent/frontend"? Y
# ? Which scope? 选择你的账号
# ? Link to existing project? N
# ? Project name? medsignal-frontend
# ? Framework preset? Next.js
# ? Root directory? ./
# 部署完成后获得 https://medsignal-frontend.vercel.app
```

在 Vercel 控制台设置环境变量：
- `NEXT_PUBLIC_API_URL` = 你的后端地址（如 https://yibao-api.onrender.com）

### 3.2 后端部署到 Render（免费套餐）

1. Fork 仓库到你的 GitHub
2. 打开 https://render.com → New → Web Service
3. 连接 GitHub 仓库，选择 `medsignal-agent`
4. 配置：
   - **Name**: `medsignal-api`
   - **Runtime**: Python
   - **Root Directory**: `backend`
   - **Build Command**: `pip install -r requirements.txt && python scripts/init_db.py`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Health Check**: `/api/health`
5. 环境变量（在 Render 控制台填写）：

| Key | Value | 说明 |
|---|---|---|
| `LLM_API_KEY` | sk-xxx | 商汤 API Key |
| `LLM_BASE_URL` | https://token.sensenova.cn/v1 | |
| `LLM_MODEL` | sensenova-6.7-flash-lite | |
| `DASHSCOPE_API_KEY` | sk-xxx | 阿里 API Key（可选） |
| `OCR_API_KEY` | xxx | OCR.space Key（可选） |

6. 点击 Create Web Service，等待部署完成

> 项目已包含 `render.yaml`，也可直接使用 Blueprint 部署。

### 3.3 自建服务器部署（Nginx 反向代理）

适合有自己服务器的场景，项目已提供 `nginx.conf` 配置。

```bash
# 1. 后端：用 gunicorn 跑多进程
pip install gunicorn
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000

# 2. 前端：构建静态产物
cd frontend && npm run build
# 将 .next/standalone 和 .next/static 部署到服务器

# 3. Nginx：使用项目提供的 nginx.conf
sudo cp nginx.conf /etc/nginx/sites-available/yibao
sudo ln -s /etc/nginx/sites-available/yibao /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

## 环境变量说明

### 后端环境变量（backend/.env）

| 变量名 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `DATABASE_URL` | 是 | sqlite+aiosqlite:///./yibao.db | 数据库连接串 |
| `REDIS_URL` | 否 | redis://localhost:6379 | Redis 连接串 |
| `LLM_API_KEY` | 否* | — | 商汤 SenseNova API Key |
| `LLM_BASE_URL` | 否 | https://token.sensenova.cn/v1 | LLM 接口地址 |
| `LLM_MODEL` | 否 | sensenova-6.7-flash-lite | 主力模型 |
| `DASHSCOPE_API_KEY` | 否 | — | 阿里 DashScope API Key（备选） |
| `DASHSCOPE_MODEL` | 否 | qwen-plus | 备选模型 |
| `OCR_API_KEY` | 否 | — | OCR.space API Key |
| `OCR_API_URL` | 否 | https://api.ocr.space/parse/image | OCR 接口 |
| `CHROMA_PERSIST_DIR` | 否 | ./chroma_data | 向量库存储路径 |
| `YIBAO_API_KEY` | 否 | — | API 鉴权密钥（不填则开放） |

> *不配置 `LLM_API_KEY` 时系统进入降级模式，AI 对话使用预设回复，其他功能正常。

### 前端环境变量（frontend/.env.local）

| 变量名 | 必填 | 默认值 | 说明 |
|---|---|---|---|
| `NEXT_PUBLIC_API_URL` | 是 | http://localhost:8000 | 后端 API 地址 |

## 常见问题排查

### Q1: 后端启动报 `ModuleNotFoundError`

```bash
# 确保虚拟环境已激活且依赖已安装
source venv/bin/activate        # macOS/Linux
.\venv\Scripts\Activate.ps1     # Windows
pip install -r requirements.txt
```

### Q2: 前端页面显示"API 未连接"

1. 确认后端已启动：访问 http://localhost:8000/api/health
2. 确认 `NEXT_PUBLIC_API_URL` 配置正确
3. 检查浏览器控制台 CORS 错误
4. 后端已配置 `allow_origins=["*"]`，一般不会有 CORS 问题

### Q3: AI 对话回复"降级模式"

说明未配置 `LLM_API_KEY`。编辑 `backend/.env` 填入商汤 API Key 后重启后端。

### Q4: `sentence_transformers` 安装失败

这是可选依赖（知识库嵌入用），安装失败不影响核心功能：

```bash
# 方式1：跳过（系统自动降级）
# 方式2：用 conda 安装
conda install -c conda-forge sentence-transformers
```

### Q5: Docker 构建很慢

```bash
# 使用国内镜像加速
# 在 Docker Desktop 设置中添加镜像：
# https://registry.docker-cn.com
```

### Q6: 数据库初始化失败

```bash
# 删除旧数据库重新初始化
rm backend/yibao.db              # macOS/Linux
del backend\yibao.db             # Windows
python scripts/init_db.py
```

### Q7: 端口被占用

```bash
# 后端换端口
uvicorn app.main:app --port 8001

# 前端换端口
npm run dev -- -p 3001
# 同时更新 NEXT_PUBLIC_API_URL
```
