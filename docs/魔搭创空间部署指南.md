# MedSignal 魔搭创空间部署指南

> 目标：把 MedSignal Demo 部署到魔搭社区（ModelScope）创空间，获得**公网可访问的链接**，
> 并通过 GitHub Actions 实现**推送即自动部署** + **每 5 分钟保活**，让公网一直可用。

## 1. 方案架构

```
浏览器 ──https──▶ https://<space>.<owner>.modelscope.cn:7860
                        │
                魔搭创空间容器（单容器全栈）
                        │
        Next.js standalone (0.0.0.0:7860，对外)   ←── 前端页面
              │  rewrites 代理 /api/*
              ▼
        FastAPI uvicorn (127.0.0.1:8000，内部)     ←── 后端 API
              │
        SQLite + 规则引擎（DEMO_OFFLINE=true，离线可跑）

GitHub Actions：
  deploy-modelscope.yml   push 时组装部署包 → 推送到创空间 git 仓库 → 魔搭自动构建
  keepalive.yml           每 5 分钟 curl /api/health，防止创空间休眠
```

关键决策点：

- 魔搭创空间支持 Docker 部署，但**对外端口固定为 `7860`**，且一个容器只能对外一个服务，所以把 Next.js 放在 7860，FastAPI 放容器内 8000，由 Next 的 `rewrites` 同域代理 `/api/*`。
- 前端构建时 `NEXT_PUBLIC_API_URL` 显式设为空 → `src/lib/api.ts` 走**相对路径** `/api/...`，无需提前知道公网域名（代码已适配，见 `frontend/src/lib/api.ts`）。
- 后端以 `DEMO_OFFLINE=true` 启动：跳过 LLM/知识库加载，全程规则引擎离线运行，**不需要任何 API Key**，也避免了在免费实例上加载大模型。
- 魔搭版依赖剔除 `sentence-transformers`（连带整个 torch，体积数 GB，代码并未直接 import），详见 `deploy/modelscope/requirements-modelscope.txt`。

## 2. 前置条件（必须用户完成）

1. 注册并登录 [魔搭社区](https://www.modelscope.cn)。
2. **完成实名认证**（个人中心 → 实名认证，绑定阿里云账号）。Docker 创空间只对完成实名认证的用户开放。
3. 生成**访问令牌**：个人中心 → 设置 → 访问令牌 → 新建令牌（勾选写权限）。

## 3. 创建创空间（一次性操作）

在魔搭社区页面上：

1. 顶部进入「创空间」→「创建创空间」。
2. 填写：
   - 名称：如 `medsignal-demo`（即 `SPACE_NAME`，字母数字中划线）
   - 可见性：公开（Private 无法被公网访问）
   - SDK：选择 **Docker**
   - 资源：免费 CPU 实例即可（不需要 GPU）
3. 创建完成后，创空间是一个空的 Git 仓库：
   `https://www.modelscope.cn/studios/<用户名>/<创空间名>.git`

> 首次部署走「GitHub Actions 自动推送」即可，无需手动上传任何文件。

## 4. 配置 GitHub Actions 凭据

在本仓库 GitHub 页面 → **Settings → Secrets and variables → Actions** 配置：

| 类型 | 名称 | 值 |
|------|------|-----|
| Secret | `MODELSCOPE_USERNAME` | 魔搭用户名（如 `yigenfeng0707`） |
| Secret | `MODELSCOPE_TOKEN` | 第 2 步生成的访问令牌 |
| Secret | `MODELSCOPE_DEMO_URL` | 部署完成后创空间的公网地址，如 `https://medsignal-demo-xxx.modelscope.cn` |
| Variable | `MODELSCOPE_SPACE_NAME` | 创空间名，如 `medsignal-demo` |

## 5. 触发部署

两种方式：

- **自动**：push 代码到 `main` 且涉及 `backend/`、`frontend/`、`deploy/modelscope/` 时自动触发。
- **手动**：Actions → `Deploy to ModelScope` → Run workflow。

流程：GitHub 组装部署包（后端源码 + 前端源码 + Dockerfile + ms_deploy.json）→
推送到创空间 Git 仓库 → 魔搭平台自动 Docker 构建（约 5-15 分钟）→ 上线。

构建完成后访问创空间页面，点击「上线空间展示」；若平台配置了自动上线则会直接可用。

## 6. 公网访问与保活

### 6.1 域名格式（重要）

魔搭创空间上线后会分配**两种公网域名**，必须区分使用：

| 域名格式 | 实际示例 | 用途 | 鉴权 |
|---|---|---|---|
| `https://<owner-prefix>-<space>.ms.show` | `https://gsym236998-medsignal-demo.ms.show` | 浏览器访问前端 + Next.js rewrites 同域代理 `/api/*` | 公开（无需 Token） |
| `https://studio-<owner-prefix>-<space>.api-inference.modelscope.net` | `https://studio-gsym236998-medsignal-demo.api-inference.modelscope.net` | API 客户端直连后端 | **需魔搭 SDK Token** |

**路演/演示统一使用 `.ms.show` 域名**：浏览器请求 `/api/health` / `/api/eeg/states` / `POST /api/agents/chat` 等都通过 Next.js rewrites 同域代理到容器内 FastAPI，**规避魔搭 SDK Token 校验**。

> ⚠️ 用 `curl` 直连 `.api-inference.modelscope.net` 会返回 `Authentication failed, please make sure that a valid ModelScope token is supplied.`，必须走 `.ms.show` 域名或加上 `Authorization: Bearer <MODELSCOPE_TOKEN>`。

实际部署后从创空间页面复制真实地址（`<owner-prefix>` 由魔搭分配，不是用户名本身）。

### 6.2 休眠与保活

- **休眠机制**：魔搭公开创空间空闲一段时间会自动休眠（官方暂不支持自主配置休眠策略）。
  休眠后首次访问会自动唤醒，但冷启动需要数十秒。
- **保活程序**：本仓库 [keepalive.yml](../.github/workflows/keepalive.yml) 已配置 GitHub Actions 定时任务，**每 5 分钟**
  请求一次 `/api/health`，让实例保持活跃。public 仓库的 GitHub Actions 免费额度无上限，可长期运行。
- **配置**：在 GitHub Secrets 中设置 `MODELSCOPE_DEMO_URL = https://<owner-prefix>-<space>.ms.show`（注意用 `.ms.show` 域名）。
- 备用保活：也可用 [UptimeRobot](https://uptimerobot.com)（免费 50 个监控，5 分钟间隔）指向
  `https://<owner-prefix>-<space>.ms.show/api/health`。

## 7. 常用操作

- **更新代码**：push 到 main 即自动重新部署；或手动 Run workflow。
- **修改环境变量**：非密钥变量改 `deploy/modelscope/ms_deploy.json`；密钥（如需接入真实 LLM）
  在创空间「设置 → 环境变量」中添加，例如关闭离线模式并配置 `DASHSCOPE_API_KEY` 后可启用真实 AI 对话。
- **停止部署**：创空间设置中停用或删除。

## 8. 常见问题

| 问题 | 处理 |
|------|------|
| 构建失败：镜像拉取超时 | 重跑 workflow；魔搭构建平台对 Docker Hub 有加速 |
| 访问 502/504 | 冷启动中，等待 1 分钟后刷新；保活任务会逐步缓解 |
| 登录/注册不可用 | Demo 模式为免登录体验模式，属预期 |
| 想启用 AI 对话 | 创空间设置加 `DASHSCOPE_API_KEY`，并把 `DEMO_OFFLINE` 改为 `false` |
| 数据库重启后重置 | 免费实例不保证持久化，Demo 数据可重建属预期 |

## 9. 部署文件说明

```
deploy/modelscope/
├── Dockerfile                    # 全栈单容器镜像（前端 7860 + 后端 8000）
├── ms_deploy.json                # 魔搭部署配置（sdk_type=docker, port=7860, env）
├── entrypoint.sh                 # 容器入口（先后端后前端，同域代理）
└── requirements-modelscope.txt   # 精简依赖（剔除 torch 等重型包）
```
