## 功能一：智能对话（首页）

首页是 AI 智能对话界面，您可以像聊天一样咨询医保问题。

### 基本操作

1. 在底部输入框输入您的问题
2. 按 Enter 键或点击发送按钮
3. 等待 AI 回复（通常 3-10 秒）
4. 回复下方可展开"证据链"查看 AI 推理过程

### 支持的问题类型

| 问题示例 | 对应智能体 | 说明 |
|---|---|---|
| "我的医保卡里有多少钱" | 权益管家 | 查询个人权益信息 |
| "我有糖尿病能享受什么政策" | 政策参谋 | 精准匹配医保政策 |
| "帮我看看我的健康风险" | 健康卫士 | 健康评分与预警 |
| "帮我做脑电健康评估" | 脑电卫士 | EEG 脑电分析 ⭐ |
| "心脏搭桥手术能报多少" | 报销助手 | 报销金额测算 |
| "我压力大有什么政策能帮" | 脑电+政策 | 多智能体协作 |

### 多智能体协作

当您的问题涉及多个领域（如"我压力大有啥政策能帮"），系统会自动识别复合意图，并行调度多个智能体：

- 回复会标注"编排智能体"标签
- 底部显示参与协作的智能体列表
- 每个智能体的结果可分别查看

### 证据链

每条 AI 回复下方可展开"证据链"，展示：
- 使用的智能体及推理过程
- 引用的政策条款
- 计算依据和数据来源

路径：侧边栏 → **医保权益**

### 多场景对比

- 社区医院 vs 三甲医院
- 在职 vs 退休
- 本地 vs 跨省就医

## 功能三：报销测算与预审

路径：侧边栏 → **报销预审**

### 3.1 报销测算

输入预估费用，系统自动计算报销金额：

1. 选择就医场景（门诊/住院）
2. 选择医院等级（社区/二级/三级）
3. 输入预估费用金额
4. 点击"测算"按钮
5. 查看结果：
   - **报销金额**：医保可报销的金额
   - **个人自付**：需要自己承担的金额
   - **7 步推导**：完整计算过程（起付线→统筹基金→封顶线→大病保险→...）
   - **多场景对比**：6 种场景的报销差异

### 3.2 发票预审（OCR）

上传医疗发票图片，系统自动识别并计算：

1. 点击"上传发票"区域
2. 选择发票图片（支持 JPG/PNG，<12MB）
3. 系统自动 OCR 识别发票信息
4. 显示识别结果和报销计算
5. 可手动修正识别错误后重新计算

> 需要 OCR API Key 支持，未配置时使用演示发票。

## 功能四：健康画像与主动预警

路径：侧边栏 → **健康画像**

### 4.1 五维健康评分

系统从 5 个维度评估您的健康状况：

| 维度 | 说明 | 数据来源 |
|---|---|---|
| 慢病风险 | 糖尿病/高血压等风险等级 | 病历记录 |
| 用药安全 | 药物相互作用风险 | 用药记录 |
| 就医频率 | 近期就医是否异常频繁 | 就诊记录 |
| 生活习惯 | 吸烟/饮酒等风险因素 | 健康档案 |
| 体检指标 | 血压/血糖等异常项 | 体检数据 |

### 4.2 雷达图

五维评分以雷达图展示，绿色区域越大代表越健康。

### 4.3 主动预警

登录时系统自动检查健康风险，在首页顶部横幅展示：
- **红色（高危）**：需立即关注，如严重药物相互作用
- **黄色（中危）**：建议关注，如慢病控制不佳
- 每条预警包含：问题描述 + 建议措施

### 4.4 用药相互作用检测

如果您同时在用多种药物，系统会自动检测：
- 阿司匹林 + 抗凝血药 → 高风险（出血）
- 降压药 + 利尿剂 → 中风险（需调整剂量）
- 安全组合 → 绿色提示

## 功能五：脑电健康评估（关键医疗信号识别）

路径：侧边栏 → **脑电健康** ⭐

这是本系统的核心创新功能，通过 EEG 脑电信号评估心理健康，并联动医保政策。

### 5.1 发起脑电采集

1. 进入脑电健康页面
2. 选择心理状态预设（用于模拟不同场景）：
   - **放松**：模拟冥想/休息状态
   - **专注**：模拟工作/学习状态
   - **高压力**：模拟紧张/焦虑状态
   - **疲劳**：模拟过度劳累状态
   - **睡眠不足**：模拟失眠状态
3. 点击"开始采集"按钮
4. 系统生成 4 通道脑电信号（模拟 Muse 设备）

### 5.2 查看评估结果

采集完成后展示：

**4 通道实时波形**
- TP9 / AF7 / AF8 / TP10（Muse 标准布局）
- 256Hz 采样率，实时波形动画

**五频段功率分析**
- δ (Delta) 0.5-4Hz：深睡眠
- θ (Theta) 4-8Hz：困倦/创造力
- α (Alpha) 8-13Hz：放松
- β (Beta) 13-30Hz：活跃思考
- γ (Gamma) 30-100Hz：高级认知

**四维健康指标**（0-100 分）

| 指标 | 计算方法 | 高分含义 |
|---|---|---|
| 压力指数 | α/β 比值反比 | 分数越高压力越大 |
| 注意力 | θ/β 比值反比 | 分数越高越专注 |
| 睡眠质量 | δ+θ 占比 | 分数越高睡眠越好 |
| 认知负荷 | β+γ 占比 | 分数越高负荷越重 |

### 5.3 脑电异常预警

当指标异常时，系统自动生成预警：

| 预警类型 | 触发条件 | 建议措施 |
|---|---|---|
| 高压力 | 压力指数 > 70 | 心理科门诊咨询 |
| 睡眠差 | 睡眠质量 < 40 | 睡眠监测检查 |
| 认知过载 | 认知负荷 > 70 | 适当休息调整 |
| 注意力低 | 注意力 < 40 | 注意力训练 |
| 情绪异常 | 情绪标签异常 | 心理健康评估 |

### 5.4 医保政策联动（核心创新）

脑电异常会自动推荐相关医保政策：

- **高压力** → 心理科门诊报销政策
- **睡眠差** → 睡眠监测医保覆盖
- **认知过载** → 职业健康检查补贴
- **注意力低** → 儿童注意力训练（如适用）
- **情绪异常** → 心理咨询医保报销

每条联动推荐展示：
- 触发原因（脑电指标证据）
- 推荐政策名称
- 报销比例和额度
- 办理流程

### 5.5 历史趋势

查看历次脑电评估的趋势变化：
- 压力指数趋势线
- 睡眠质量趋势线
- 对比不同时期的变化

### 5.6 实时流模拟

点击"实时模式"可查看模拟实时脑电数据流：
- 波形实时滚动
- 指标实时更新

## 功能七：可信数据空间

路径：侧边栏 → **数据安全**

### 7.1 数据授权管理

控制哪些数据可以被 AI 访问：

1. 查看授权矩阵（4 种数据类型 × 授权状态）：
   - 医保缴费记录
   - 就诊病历
   - 用药记录
   - 脑电数据 ⭐
2. 点击开关启用/禁用某类数据授权
3. 每次授权变更都会记录到审计日志

### 7.2 审计日志

查看所有数据访问记录：
- 谁在什么时间访问了什么数据
- 访问目的（AI 对话/报销计算/...）
- 数据指纹（proof_hash）用于追溯

### 7.3 区块链存证

关键操作会上链存证：
- 授权变更记录
- 数据访问记录
- 每条记录有唯一的 proof_hash
- 可在区块链浏览器验证（演示模式）

### 7.4 数据流转可视化

路径：侧边栏 → **数据安全** → **数据空间**

以可视化方式展示数据如何在各智能体之间流转：
- 隐私计算"可用不可见"
- 数据不出域的验证过程
- 各智能体的数据访问范围

## 功能八：医学影像标注工作台

路径：侧边栏 → **影像标注** ⭐

这是系统的另一核心创新功能：AI 医学影像病灶检测 + 医师逐框复核的人机协同工作流。

### 8.1 发起 AI 分析

1. 进入「影像标注」页面
2. 选择检查类型：胸片 / 肺 CT / 脑 MRI
3. 点击「开始 AI 分析」
4. AI 自动生成影像并框出疑似病灶（bbox 标注）

### 8.2 理解 AI 标注

- 每处病灶标注显示：类别、置信度、严重度
- 颜色标识：🔴 高危 / 🟡 中危 / 🟢 低危
- 底部计数：AI 预标注 N 处 / 确认 N 处 / 驳回 N 处

### 8.3 医师复核（核心）

1. 对每处 AI 标注选择「确认」或「驳回」
2. 点击「新增标注」→ 在影像上点击病灶中心 → 选择类别/严重度/大小 → 添加医生标注
3. 复核完成后点击「提交医生复核」

> ⚠️ **医疗安全边界**：AI 预标注只是建议，医师复核才是裁决。只有复核通过的标注才会进入最终报告。

### 8.4 结构化报告与政策联动

- 复核完成后生成最终结构化报告：病灶清单、风险等级、就诊建议
- 影像异常自动联动相关政策与就诊建议
- 历史记录保存每次检查的发现数、风险等级、政策联动数

## 功能九：数字人体档案

路径：侧边栏 → **数字人体档案**

1. 通过顶部用户切换器选择患者，3D 查看器会加载对应性别的解剖模型和既有就诊档案。
2. 拖动旋转、滚轮缩放；悬停器官或发光标记可查看记录数，点击后打开完整时间线。
3. 使用“档案聚焦”只显示已有记录的部位；使用底部时间轴回放不同时间点前的累计档案。
4. 新记录通过对话/上传自动归档，或通过数字人体档案 API 追加，页面会自动轮询刷新。

> 数字人体仅用于资料整理和解剖位置展示，不自动检测或推断疾病，不构成诊断或治疗建议。

## 用户切换

右上角的用户切换器可切换内置或自行添加的用户，体验个性化服务：

| 用户 | 特点 | 适合演示 |
|---|---|---|
| 张阿姨 | 糖尿病慢病用户 | 政策匹配 + 报销 |
| 李大爷 | 退休老人，多种慢病 | 健康预警 + 大病保险 |
| 王先生 | 年轻在职 | 权益查询 |
| 赵女士 | 高血压患者 | 用药安全 |
| ... | 内置 10 个画像 | 不同场景 |

切换用户后，全站数据（权益/健康/政策/预警）会联动更新。

点击用户列表顶部的“添加新用户”，填写姓名、年龄、性别、城市、参保类型和就业状态后保存。系统会自动切换到新用户；聊天上下文与数字人体档案也会同步更新。新用户初始没有就诊或健康记录，可随后通过相应功能补充。

## 常见问题

### Q: AI 回复很慢怎么办？

A: AI 回复依赖 LLM API，通常 3-10 秒。如超过 30 秒：
1. 检查网络连接
2. 查看后端日志是否有 API 调用错误
3. 系统会自动降级到预设回复

### Q: 脑电评估的数据是真实的吗？

A: 当前版本使用合成信号模拟真实 EEG 数据（4 通道/256Hz/五频段），用于演示关键医疗信号识别理念。接入真实 Muse 设备后，算法引擎可直接处理真实信号。

### Q: 我的健康数据安全吗？

A: 系统采用可信数据空间架构：
- 所有数据访问需您授权
- 访问记录上链存证
- 隐私计算"可用不可见"
- 您可随时撤销授权

### Q: 报销计算结果准确吗？

A: 报销引擎基于浙江省医保政策规则实现，包含起付线、统筹基金、大病保险等 7 步计算。实际报销金额以医保局审核为准，本系统结果仅供参考。

### Q: 如何体验多智能体协作？

A: 在首页对话框输入复合问题，如：
- "我压力大有啥政策能帮"（脑电+政策）
- "心脏搭桥能报多少+有什么政策"（报销+政策）
系统会自动识别复合意图，并行调度多个智能体。

### Q: 政策推荐是针对我的吗？

A: 是的。政策匹配引擎根据您的年龄、慢病、参保类型等画像信息精准匹配。切换不同用户会看到不同的政策推荐。

### Q: 可以在手机上使用吗？

A: 系统采用响应式设计，支持手机浏览器访问。推荐使用 Chrome / Safari 最新版。
