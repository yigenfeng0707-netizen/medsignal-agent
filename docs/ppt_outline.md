## Slide 5: Architecture — 多智能体架构

**标题**：五大智能体 · 协同作战

**核心内容**：
- 编排智能体（Orchestrator）：意图识别 + 路由分发 + 结果聚合
- 权益管家（Coverage Agent）：医保权益查询与测算
- 报销助手（Claims Agent）：OCR票据识别与报销预审
- 健康卫士（Health Agent）：健康画像与风险预警 ⭐核心
- 政策参谋（Policy Agent）：政策精准匹配与省钱计算
- 安全守门（Security Agent）：数据授权与合规审计

**视觉元素**：
- 中心辐射式架构图
- 中央：编排智能体（圆形，深蓝色）
- 五个方向辐射出五个专业智能体（圆形，不同颜色）
  - 权益管家：蓝色（盾牌图标）
  - 报销助手：绿色（文件图标）
  - 健康卫士：红色/橙色（心脏图标，加星标突出）
  - 政策参谋：紫色（书本图标）
  - 安全守门：灰色（锁图标）
- 每个智能体下方标注1-2个核心能力
- 底部：用户输入 → 编排器 → 多智能体 → 聚合结果 → 用户

**演讲备注**：
