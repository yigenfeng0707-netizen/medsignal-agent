## 一、技术类问题

### Q1：脑血管风险指数的算法依据是什么？准确率如何？

**回答要点**：
- 算法基于脑血管病脑电诊断共识（中华神经科学会）：δ波弥漫性增多+θ/α比值升高+α波节律减弱是脑血管病变早期脑电特征
- 综合三个维度加权：δ波占比(40%)+θ/α比值(35%)+α波抑制(25%)
- 定位是"风险预警"非"医疗诊断"——提醒该关注了，不是告诉你得了什么病
- 设置两级阈值：≥60高风险建议48小时内检查，≥40中风险建议定期体检
- 每条预警带evidence（频段数值+正常范围），参保人可自行判断

### Q2：脑电设备和数据怎么保证质量？

**回答要点**：
- 支持消费级Muse设备（4通道/256Hz，医疗级精度足够做趋势监测）
- 信号质量检测：device_adapter.py 实时监测阻抗/接触/伪迹
- 降级策略：信号质量差时提示重新佩戴，不输出误导性结果
- 生产部署建议：社区配备医疗级设备，个人端用消费级做日常趋势

### Q3：和现有"医小保"等医保AI有什么区别？

**回答要点**：
- 主动预警：医小保被动问答，我们主动推送脑电健康预警
- 多模态信号识别：唯一将脑电+影像+行为三类信号统一调度的医保智能体
- 多智能体：7个专业Agent协作，非单一模型
- 全链路可解释：每个决策有频段依据+影像坐标+政策原文

### Q4：数据安全怎么保证？

**回答要点**：
- 架构层：安全守门Agent，四级授权，敏感数据每次确认
- 技术层：对齐浙江医保数据要素战略"可用不可见、可控可计量、可信可追溯"
- 合规层：遵守《个人信息保护法》《数据安全法》，脑电数据属敏感个人信息，单独同意+随时撤回
- 审计层：所有数据访问完整日志+区块链存证

### Q5：医学影像 AI 预标注的准确率如何？用了什么模型？

**回答要点**：
- 当前版本基于确定性病灶生成 + 解剖学规则检测，保证路演可复现
- AI 预标注输出：bbox 归一化坐标 + 置信度 + 严重度分级（高/中/低危）
- 核心设计是"医师在环"——AI 只做预标注建议，医师复核才是裁决，准确率由医师把关
- 生产路径：接入真实脱敏影像 + 迁移学习（如 YOLOv8-medical），目标召回率 ≥90%
- 测试：影像引擎单元测试全绿，bbox 坐标精度验证通过

### Q6：医师复核流程为什么不是"AI 直接出报告"？

**回答要点**：
- 医疗安全底线：AI 预标注是建议权，医师复核是裁决权
- 流程：AI 检测 → bbox 框选 → 医师逐框确认/驳回/新增标注 → 生成最终报告
- 这是医疗 AI 的安全边界——让 AI 当助手，让医师当裁判
- 对标 FDA SaMD（Software as Medical Device）监管思路：AI 辅助决策，不替代医师

## 三、创新类问题

### Q9：多模态信号识别的创新点到底在哪？

**回答要点**：
- 三大信号统一由编排智能体调度：脑电频域分析 + 影像病灶检测 + 行为模式分析
- 核心创新：
  1. 医师在环：影像 AI 预标注必须医师逐框复核才能出报告（建议权给 AI，裁决权给人）
  2. 可解释信号：脑电指标有频域证据链、病灶有坐标框、政策有原文引用
  3. 主动健康范式：信号异常 → 主动预警 → 政策红利自动连接

### Q10：认知衰退筛查和医院做的MMSE有什么区别？

**回答要点**：
- 互补关系，非替代
- MMSE是量表评估（需医生操作，主观性强），我们是脑电客观指标
- 脑电可高频监测（日常趋势），MMSE低频（年度体检）
- 脑电异常→触发MMSE确认→医保政策联动，形成筛查闭环

### Q11：为什么选择"关键医疗信号识别"这个方向？

**回答要点**：
- 对齐 VentureD 医疗赛道要求：围绕真实医疗场景，而非概念展示
- 三类信号都是"身边有但被忽视"的：脑电（压力/睡眠）、影像（病灶）、信息（政策红利）
- 信号有，识别没有；识别有，翻译没有；翻译有，行动没有——我们补全这条链路
- 最终落到患者可行动的结果：预警 + 政策匹配 + 就医引导

## 四、政策与合规类问题

### Q12：浙江医保政策参数准确吗？

**回答要点**：
- 演示用参数参考浙江/杭州公开政策整理，已简化
- 生产环境对接医保局最新政策API
- 规则库JSON结构化，政策更新只需改配置不改代码
- 已覆盖3险种×3级别×门诊住院+大病保险+门诊慢病

### Q13：脑电数据属于敏感个人信息，合规吗？

**回答要点**：
- 脑电数据属敏感个人信息，处理需单独同意
- 系统设计：每次脑电采集前明确授权，支持随时撤回
- 数据最小化：只采集评估所需频段功率，不存储原始波形长期
- 脱敏存储：session_id关联，不直接绑定身份证号
- 区块链存证：所有访问可追溯

### Q14：影像数据是真实的吗？涉及患者隐私吗？

**回答要点**：
- 演示用影像为 SVG 确定性生成的高仿真医学影像，非真实患者数据
- 病灶按真实解剖位置分布参数化生成，可复现
- 生产部署将接入脱敏 DICOM 数据，严格遵守《医疗器械数据安全指南》
- 影像报告必须医师复核签字后方可生效，AI 预标注仅作辅助

## 五、技术深挖类问题

### Q15：289项测试覆盖什么？

**回答要点**：
- EEG引擎55+项（频域分析/五维指标/8条预警/政策联动）
- 健康引擎11项、报销计算14项、政策匹配12项
- 影像引擎37项（病灶检测/bbox精度/复核流程/报告生成）
- 编排器离线链路32项（意图识别降级/多意图路由/复合查询兑底）
- 路由层离线测试20项（会话持久化/404/409归属校验/EEG端点）
- 冒烟测试68项（8个Router全链路+AI对话），总覆盖率65.03%

### Q16：如果现场Demo失败怎么办？

**回答要点**：
- 三级降级：LLM（SenseNova）→ DashScope → 规则引擎，保证不翻车
- 线上 + 本地双部署：魔搭创空间公网 + 本地 Docker
- 预录视频兜底：Demo 视频分镜脚本已准备
- 合成信号稳定：EEG/影像均为确定性生成，不受设备/网络影响

### Q17：Welch PSD 的参数选择依据？

**回答要点**：
- Hann窗（减少频谱泄漏）+ 50%重叠（平衡频率分辨率与方差）
- FFT 点数 256（与采样率匹配，1Hz 分辨率）
- 五频段划分基于国际临床脑电标准：δ(1-4Hz)/θ(4-8Hz)/α(8-13Hz)/β(13-30Hz)/γ(30-45Hz)

### Q18：多智能体比单模型有什么优势？

**回答要点**：
- 可解释：每个Agent有明确职责和证据链，非黑箱
- 可扩展：新增信号类型只需加Agent，不改整体架构
- 可降级：单个Agent故障不影响其他，系统级容错
- 复合意图：编排器可并行调度多Agent（如"脑电异常+政策省钱"）

## 七、新增能力与数据真实性类问题（v3.0 新亮点）

### Q46：脑电数据的“双源真实数据集”是什么？怎么证明不是编的？

**回答要点**：
- 双源均为国际公开数据集：PhysioNet eegmmidb（运动想象脑电，ODC-By 许可）+ EEGEmotions-27（88 人×27 类细粒度情绪，CC BY-NC 4.0，IEEE Access 2025）
- 可验证链路：接入脚本 scripts/ingest_real_eeg.py 全程可复现 → 每条记录登记在 data/real_eeg/manifest.json（含许可/引用/受试者元信息）→ API GET /api/eeg/real/list 现场可查 → 前端“真实数据集”面板展示来源与许可
- 情绪维度接入时逐通道去均值后按 Emotiv 0.51μV/LSB 标定，保证频域指标计算口径正确
- 两份许可均为非商业兼容：比赛/科研展示用途合规，来源与 DOI 已在 docs/EEG数据集调研.md 统一列出

### Q47：多用户并发下，动态用户管理和会话隔离怎么保证？

**回答要点**：
- 会话归属双重校验：user_id + conversation_id，跨用户访问会话直接返回 409，测试已覆盖
- 新增用户后全站即时联动：对话/健康画像/数字人体档案共用同一用户表，新增即生效，现场可演示从 0 到全站联动 <10 秒
- 会话持久化：重启后历史完整可回放，PostgreSQL 迁移只改配置不改代码
- 智能体相互隔离：单 Agent 故障不影响其他，编排层容错已测试

### Q48：LLM 完全不可用时系统的降级边界在哪里？

**回答要点**：
- 三级降级：SenseNova → DashScope → 规则引擎；意图识别 30 秒超时降级关键词路由；智能体调用 40 秒超时降级本地引擎；复合意图全失败有统一兑底文案
- 脑电/影像/报销三大核心均为本地确定性引擎，完全不依赖 LLM，降级模式 Demo 不翻车
- 52 项离线降级链路专项测试验证（test_orchestrator_offline.py + test_routers_offline.py），全部在 LLM 不可用条件下断言行为正确
- 线上验收实测：/api/health/detailed 返回 demo_mode=false（LLM 真实生效），降级仅在异常时触发
